## How this list is built

Every entry is discovered from a trusted reference (a vouched clearnet source, an authoritative directory such as the SecureDrop directory, or a link from a site already verified), then passed through an automated moderation gate that filters illegal content and dead or thin pages. **500** submitted or discovered sites have been filtered out as unsafe or illegitimate.
